# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |

## Reporting a Vulnerability
If you discover an integer overflow, ISR deadlock, or CAN state-machine bypass in this driver or RFC harness, please email `abz.king.1.9.2003@gmail.com` or open a private GitHub Security Advisory rather than posting public exploit payloads prior to remediation.
